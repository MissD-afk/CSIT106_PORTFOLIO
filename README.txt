MAVIC D. STUDENT PORTFOLIO
=========================

HOW TO OPEN
1. Extract this ZIP folder.
2. Open the mavic_portfolio folder in Visual Studio Code.
3. Open index.html in your browser, or use the Live Server extension.

PAGES
- index.html: Home
- about.html: About
- education.html: Education
- skills.html: Skills
- projects.html: Projects
- achievements.html: Achievements
- contact.html: Contact

CUSTOMIZE
- Replace assets/profile-placeholder.svg with your own profile photo. For easiest setup, put your photo in assets and change the image src in index.html.
- Edit your information directly in each HTML page.
- Change colors in the :root section at the top of style.css.
- Update the GitHub link and email if needed.
- The contact form opens the visitor's email app; it does not store messages in a database.
- The sample projects are based on project topics discussed previously. Edit them to match your final work.

This is a static website template. Internet is needed to load Google Fonts; the rest of the design runs locally.
